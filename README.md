# Mis tareas

Lista de tareas sencilla hecha con HTML, CSS y JavaScript (sin dependencias).

- Agregar tareas
- Marcarlas como hechas
- Borrarlas (una a una o todas las hechas)
- Se guardan automáticamente en el navegador (`localStorage`)
- Diseño pensado para iPad (botones grandes, modo oscuro automático)

## Uso

Abre `index.html` en el navegador. Para usarla en el iPad, publícala (por ejemplo con GitHub Pages) y abre el enlace en Safari; desde *Compartir → Añadir a pantalla de inicio* queda como una app.
